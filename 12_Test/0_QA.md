# Testing Interview Q&A List

1.  What is Unit Testing, and what should a good unit test cover?  
    什麼是 Unit Testing？一個好的 unit test 應該涵蓋哪些內容？

2.  What is the difference between TDD (Test-Driven Development) and BDD (Behavior-Driven Development)?  
    TDD 和 BDD 的差異是什麼？

3.  What is TDD? Describe the Red-Green-Refactor cycle.  
    什麼是 TDD？請描述 Red-Green-Refactor 循環。

4.  What is BDD? How does it differ from TDD in terms of collaboration and test language?  
    什麼是 BDD？它與 TDD 在協作方式和測試語言上有何不同？

5.  What is the difference between a Mock and a Stub?  
    Mock 和 Stub 的差異是什麼？

6.  What is a Spy in testing? How does it differ from a Mock?  
    測試中的 Spy 是什麼？它和 Mock 有何不同？

7.  What is Integration Testing? How does it differ from Unit Testing?  
    什麼是 Integration Testing？它和 Unit Testing 的差異是什麼？

8.  What is System Testing? What is its scope and purpose?  
    什麼是 System Testing？它的範圍和目的是什麼？

9.  What is End-to-End (E2E) Testing? How does it differ from System Testing?  
    什麼是 E2E Testing？它和 System Testing 有何不同？

10. What is Acceptance Testing? Who typically performs it?  
    什麼是 Acceptance Testing？通常由誰來執行？

11. What is the difference between Alpha Testing and Beta Testing?  
    Alpha Testing 和 Beta Testing 的差異是什麼？

12. What is Regression Testing, and when should it be performed?  
    什麼是 Regression Testing？應該在什麼時候執行？

13. What is Smoke Testing? What is its role in a CI/CD pipeline?  
    什麼是 Smoke Testing？它在 CI/CD 流程中扮演什麼角色？

14. What is Sanity Testing? How does it differ from Smoke Testing?  
    什麼是 Sanity Testing？它和 Smoke Testing 的差異是什麼？

15. What is the Testing Pyramid? Why does it recommend more unit tests than E2E tests?  
    什麼是 Testing Pyramid？為什麼它建議 unit test 數量多於 E2E test？

16. What is Code Coverage? What are its limitations as a quality metric?  
    什麼是 Code Coverage？用它作為品質指標有哪些限制？

17. What is Mutation Testing? Why is it useful beyond measuring code coverage?  
    什麼是 Mutation Testing？為什麼它比只看 code coverage 更有用？

18. What is Property-Based Testing? How does it differ from Example-Based Testing?  
    什麼是 Property-Based Testing？它和 Example-Based Testing 有何不同？

19. What is Contract Testing? When is it especially useful in a microservices architecture?  
    什麼是 Contract Testing？在 microservices 架構中它特別解決什麼問題？

20. What is Load Testing vs. Stress Testing vs. Performance Testing?  
    Load Testing、Stress Testing、Performance Testing 三者有何不同？

21. What is the difference between White-Box Testing and Black-Box Testing?  
    White-Box Testing 和 Black-Box Testing 的差異是什麼？

22. What is a Test Double? What are the different types (Dummy, Fake, Stub, Mock, Spy)?  
    什麼是 Test Double？有哪些類型（Dummy、Fake、Stub、Mock、Spy）？

23. What is Flaky Test? What are common causes and how do you fix them?  
    什麼是 Flaky Test？常見原因是什麼？如何修復？

24. What is Snapshot Testing? What are its trade-offs?  
    什麼是 Snapshot Testing？它的優缺點是什麼？

25. How do you decide what NOT to test?  
    你如何決定哪些東西不需要測試？
