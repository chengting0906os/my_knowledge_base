# Senior Full-Stack Engineer — Interview Preparation Checklist
# 資深全端工程師 面試準備 Checklist

> Source: Field notes — 32 applications, 9 interviews (Hsinchu Science Park + fully remote)
> https://www.threads.com/@thecindycode/post/DXjb9JZiQHa

---

## English Version

### Technical
- [ ] **Self-introduction**: Not just your background — how do *you* define yourself as an engineer?
- [ ] **Work process**: Can you walk through requirement → development → deployment clearly?
- [ ] **System design mindset**: Not just coding, but *why* you designed the system that way
- [ ] **RBAC / Access control**: Experience with role-based permission layers and security controls
- [ ] **Security / ISO 27001**: Basic awareness of enterprise compliance standards
- [ ] **Tech stack experience**: Not a list — what problems did you actually solve with each tool?
- [ ] **AI usage experience**: Nearly universal now — prepare concrete examples

### Soft Skills
- [ ] **Reason for leaving**: *How* you say it matters more than the reason itself — practice a positive framing
- [ ] **Life goals**: No perfect answer needed, but show you've thought about it
- [ ] **Career direction**: Be specific about where you want to grow

### Written Test / Fundamentals
- [ ] Data structures & algorithms basics
- [ ] SQL queries and performance tuning
- [ ] System design basics (API design, DB schema)

### Pre-interview Self-check
- [ ] Can I clearly articulate what I've built and why?
- [ ] Can I explain the reasoning behind my technical decisions?
- [ ] Am I ready to take ownership and drive solutions?

## 中文版

### 技術面
- [ ] **自我介紹**：不只列背景，能說清楚「你怎麼定義自己這個工程師」
- [ ] **工作流程**：需求 → 開發 → 部署，能描述清楚完整 delivery 流程
- [ ] **系統架構設計**：不是會寫 code，而是能解釋你為什麼這樣設計
- [ ] **RBAC 權限設計**：處理過角色分層、安全控管的經驗
- [ ] **資安 / ISO 27001**：基本概念，企業合規意識
- [ ] **技術棧經驗**：不是列清單，而是說你用來解決過什麼問題
- [ ] **AI 使用經驗**：現在幾乎每間都會問，準備具體案例

### 軟實力面
- [ ] **離職原因**：怎麼講比原因本身更重要，練習正面表達
- [ ] **人生規劃**：不需要完美答案，但要顯示你有認真想過
- [ ] **職涯期許**：你想往哪個方向走，說得具體

### 筆試 / 基本功
- [ ] 資料結構與演算法基本題型
- [ ] SQL 查詢與效能優化
- [ ] 系統設計基礎題（如 API 設計、DB Schema）

### 面試前自我檢查
- [ ] 我能不能把自己做過的事情講清楚？
- [ ] 我能不能清楚表達技術決策背後的原因？
- [ ] 我願不願意承擔責任、主動解決問題？

---

> **Key Reminder / 核心提醒**
> Senior engineers don't just write code — they communicate clearly, understand systems, and take responsibility.
> 資深工程師不只是寫程式——而是能清楚表達、理解系統、承擔責任。
